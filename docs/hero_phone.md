# Телефонний простій героїні

Телефонний простій — окреме піддерево поруч із сидячим відпочинком.
`HeroRestGraphs.rest()` один раз на початку простою вибирає між ними з рівними
вагами. Усередині телефонної гілки активність не перемикається на сидячу.
`HeroPhoneRestGraph.definition()` також можна передати як окремий `restGraph`.

## Візуальні джерела

- Основна поза: `art/hero/phone_v1/scroll_neutral.png`.
- Зовнішність і теплий шампанський колір волосся: `art/hero/reference/`.
- Атлас містить 11 кадрів, кожен згенерований окремим прозорим PNG.
  `scroll_swipe.png` виключений через різницю масштабу та яскравості.
  Копія попереднього атласу: `art/hero/phone_v1/phone-before-frame-4-removal.png`.
- Рецепт пакування: `tool/sprite_assets/manifests/hero/phone_v1.json`.
- Ігровий атлас: `assets/characters/hero/phone.png`; клітинки 512 × 512.
- Розпаковані кадри й GIF: ігнорована папка `build/`.

## Послідовність

`walk[8] → зупинка → опора на меч / рука біля пояса → діставання телефона
→ скролінг / короткий сміх → переляк → замах → кидок назад → підняття меча
→ крок → walk[0]`.

Вхід використовує справжній ресурс кадру ходіння з його rig та геометрією.
Перед запуском нового графа координатор закінчує поточний крок до `walk[8]`.
Кидок закінчується на `phone[10]`, після чого координатор запускає ходьбу
з `walk[0]`. Кліп кидка не повторює `walk[0]`, щоб не подвоювати його паузу.

Цикл телефона переважно містить паузи в основній позі; усмішка й сміх
із заплющеними очима займають коротку частину циклу. Повернення користувача
негайно перериває цей цикл, включно зі сміхом. Повернення під час входу
залишається відкладеним до завершення діставання телефона, після чого одразу
починається вихід. Пригода заблокована до завершення всього виходу.

Маркери `phoneReleased` і `swordGrabbed` визначають порядок кидка та підняття
меча. У кадрах release / grab / stride телефон ще летить за героїнею.

## Перевірка

```sh
python3 tool/sprite_assets/build.py tool/sprite_assets/manifests/hero/phone_v1.json
python3 tool/sprite_assets/verify.py tool/sprite_assets/manifests/hero/phone_v1.json --previews
flutter test --no-pub test/content/hero_phone_test.dart
```

GIF використовують таймінги, кадри, масштаби та прив'язки з Dart-кліпів:
`build/animation_previews/hero/phone_v1/{entry,scroll,wake,walk-phone-walk}-preview.gif`.
Вони перевіряють ресурси та послідовності; поведінку запущеного десктопного
застосунку потрібно оцінювати окремо.
